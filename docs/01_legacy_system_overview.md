# 01. 現行システム概要

## 5シート構成

- `入力`: 人が日々の結果を入力するフロント。
- `DB`: 入力を取り込み、税・保有日数・放棄日・入力完了を計算する中枢。
- `結果`: DBと拠点マスタから公開/確認用表示を組み立てる。
- `税収`: 税・保有を中心にした表示。
- `計算用`: ギルドマスタ、拠点マスタ、補助設定。

## データフロー

`入力 → DB（状態遷移・計算）→ 結果/税収`

重要なのは、現行ファイルが単なる勝敗表ではなく、**ギルドの占領状態を日付順に追跡する状態管理**になっていること。

## 入力の横持ち構造

通常拠点戦は `3A, 3B, 2A, 2B, 2C, 1A〜1E` の最大10枠。各枠に勝利ギルド、対戦数、（一部枠は統一）、宴会を入力する。

攻城戦は土曜に、カルフェオンとバレンシアそれぞれ `勝利 / 攻城1 / 攻城2` を入力する。

Web版では横持ちをやめ、通常拠点戦を **1戦=1レコード** にする。

## 旧版が壊れやすかった理由

- 行番号を前提に7日前/6日後を参照する。
- HSTACKのスピル先に固定値があると #REF!。
- 表示テンプレートを週単位でコピーしている。
- 未確定を #N/A で表しており、エラーと状態が混ざる。
- 旧仕様の補助列/マスタが一部残存。

Web版ではこれらをデータベースの検索・明示的な状態管理へ置き換える。
